## Documentation rules
- `docs/architecture.md` and `docs/data-model.md` describe **how it works today** — update in the same PR as the change.
- `docs/decisions/` holds ADRs: numbered, append-only, **never edited**. Superseding a decision means a new ADR that references the old one.
- `docs/features/<feature>/` holds the intent → spec → plan chain per feature.
- The Obsidian vault holds thinking and history. It is **not** authoritative for current behaviour.
