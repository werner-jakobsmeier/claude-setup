# Decisions (ADRs)

Numbered, append-only, **never edited**. To reverse a decision, add a new ADR that supersedes the old one — the record of *why* you changed your mind is worth more than a tidy file.

Filename: `NNNN-short-kebab-title.md`

Template:

```
# NNNN — Title

**Date**: YYYY-MM-DD
**Status**: accepted | superseded by NNNN

## Context
What forced a decision.

## Decision
What was chosen.

## Alternatives considered
What was rejected, and why. This is the part future-you needs.

## Consequences
What this costs, and what it makes harder.
```
